## [0.2.0] - 2026-10-16

### Changed

- **Black Steel look** — The popup and settings page use the shared OpenShield brand tokens: dark steel surfaces, warm off-white text and a crimson accent. The shield mark appears in the popup header and settings title, and the toolbar badge color matches.
- **Animated knight** — The popup header shows the knight, which reflects the connection: idle when connected, working when approvals are pending, thinking while connecting, error when disconnected or unauthorized. With reduced motion enabled, a still image is shown instead of the animation.
- **Brand assets** — New toolbar icons from the Black Steel shield, and a new README hero image and badges.

## [0.1.0]

- Initial version: settings, popup, context menu (send page or selection to a session) and tool-call approvals for a running `openshield serve` instance.
